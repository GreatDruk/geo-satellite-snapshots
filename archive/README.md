# История экспериментов

Здесь сохранены эксперименты с обучением на train и оценкой на исходной val, а также прежние фиксированные refit на train+val. Выводы собраны в [короткой истории](../docs/experiments.md), журнал обучений находится в корне репозитория.

```text
src/          Исторические реализации моделей, обучения и анализа val
notebooks/    EDA, baselines, transfer learning, TTA/ансамбли, LGFFE, AGMFA, HardShift
configs/      Настройки экспериментов и подготовленных гипотез
tests/        Проверки исторических реализаций на синтетических данных
artifacts/    Локальные веса, логи, val probabilities и числовые аудиты
```

Ноутбуки открываются из корня проекта или `archive/notebooks/`. Они находят корень автоматически, импортируют `archive.src` и используют архивные артефакты. Исходные данные лежат в `data/raw/` у корня репозитория; для Kaggle можно задать `RAW_DIR` явно. Новые обучения отключены в исследовательских ноутбуках с соответствующим флагом.

Пример исторического запуска из корня:

```bash
python -m archive.src.experiment configs/baseline_cnn.json --exp-id cnn_new_001
```

Путь конфига считается относительно `archive/`. Запуск создаёт архивные артефакты и добавляет реальную запись в корневой `experiments.csv`. Для текущего финального решения используйте `final/`.
